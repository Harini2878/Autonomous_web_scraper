
# Autonomous Web Scraper and Data Extractor

## Project Description

This project is developed using Python to automatically
extract book information from a website.

It collects product details from multiple pages
and stores the extracted information in CSV and JSON formats.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV
- JSON

## Features

1. Automatic website connection
2. Product information extraction
3. Automatic pagination
4. Error handling and retries
5. Data extraction from multiple pages
6. CSV export
7. JSON export
8. Duplicate checking
9. Data validation

## Website Used

https://books.toscrape.com/

## Installation

Install the required libraries:

pip install -r requirements.txt

## Execution

Run the main application:

python main.py

## Testing

Run the testing file:

python test_scraper.py

## Output Files

- output/products.csv
- output/products.json

## Expected Dataset

The website contains 1000 books.
The scraper aims to collect all available records.
